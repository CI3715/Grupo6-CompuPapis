# ADR 006 - Licencia MIT

## Estado

Aceptada.

## Contexto

El proyecto necesita una licencia explícita desde el inicio del desarrollo.

## Decisión

Cuentas Claras utilizará la licencia MIT.

## Alternativas consideradas

- Apache-2.0.
- GPL.

## Consecuencias

El código puede utilizarse, modificarse y redistribuirse con pocas restricciones, manteniendo el aviso de copyright y licencia.
